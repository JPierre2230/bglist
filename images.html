How it works
  1. Click Open on BGG next to a game. It opens in one shared tab, so you won't pile up tabs.
  2. On the BGG page, right-click the box picture and choose Copy image address (on a phone, long-press it).
  3. Come back here and paste into that game's box. Check the preview, then the next game is selected for you.
  4. Your progress is saved in this browser as you go. When you're done (or want to stop for now), save the file at the bottom.

Save to your website

Pictures you add here only show on this computer until you save them to GitHub. Download the file, then in your bglist repository open the data folder, choose Add file → Upload files, drop in images.json and click Commit changes. Your site shows the pictures a minute or two later.
